# Rose Pine Desktop

Окружение для Windows 10 1809+ / Windows 11 x64: GlazeWM, панель Rosé Pine с
треем и открытыми приложениями, Yazi, Alacritty, обводки, меню питания и
собственные дополнения. Основные настройки, обновление и восстановление доступны
через центр управления. Хоткеи работают на физических клавишах EN/RU.

## Установка

Запусти `RosePineDesktop-Setup-X.Y.Z.exe` из `dist`. Мастер работает для текущего
пользователя и скачивает фиксированные зависимости с официальных сайтов.
Нужен интернет; Git, Python и Node пользователю не нужны. Курсор Bibata и скрытие
панели Windows включаются отдельными флажками. Существующий WebView2 используется
повторно; при его отсутствии мастер запускает официальный установщик Microsoft.

Центр доступен в меню «Пуск» и по значку ◆ в верхней панели. После первой
установки нажми «Запустить окружение» в «Настройках» или войди в
Windows заново. Выбор браузера и рабочих пространств находится в «Настройках».

## Обновления и восстановление

GitHub пока не подключён: центр прямо сообщает об отсутствии источника.
Для подключения укажи HTTPS-адрес манифеста выпуска и нажми «Сохранить источник» в разделе «Обновления». Проверка при входе не
устанавливает обновления; уведомление предлагает открыть центр. Постоянной
службы обновлений нет. Для локальной проверки допустим абсолютный путь к JSON.

Каждая версия содержит согласованный набор конфигов и дополнений. Перед
изменением файлов сохраняется резервная копия. Занятые файлы не заменяются:
закрой соответствующий компонент и повтори установку. Терминалы и пользовательские
приложения принудительно не закрываются.

Ручные правки приводят к остановке обновления до применения конфигов. Раздел
восстановления показывает исходный файл и подготовленную новую версию. Сохрани
нужные правки, сравни файлы и повтори операцию. Центр не выполняет неявное слияние.
История открытия, кэши Yazi и данные WebView панели не являются поставляемыми
файлами и не заменяются. Откат возвращает предыдущую версию, сохраняя новые личные параметры.

Удаление восстанавливает исходные неизменённые конфиги и параметры курсора,
отключает автозапуск и возвращает панель Windows. Собственные ручные правки и
резервные копии сохраняются. Уже установленные сторонние приложения не удаляются.

## Разработка и сборка

Нужны Windows x64, .NET Framework 4.8 (компилятор C#), Node.js 22.12+ с npm,
Python 3.11+ для проверки EN/RU и Inno Setup 6.5+.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File .\tests\lifecycle.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File .\tests\installer.ps1
python .\scripts\sync-russian-keymap.py .\templates\yazi\keymap.toml .\scripts\yazi-26.9.1-default-keymap.toml --check
```

Сборка создаёт установщик, ZIP выпуска и JSON манифеста в `dist`. Проверка EXE использует отдельный идентификатор приложения и не меняет регистрацию рабочей установки. Кэши, результаты
тестов и готовые приложения не добавляются в Git. Лицензии npm собираются из
установленных зависимостей. Версии сторонних приложений и SHA-256 записаны в
`dependencies.json`; менять их следует только вместе с проверкой нового выпуска.

Структура: `templates` — конфиги; `src/bar` — изменённая панель thearturca;
`src/helpers` — исходники дополнений; `runtime` — установка, обновление и откат;
`installer` — мастер; `tests` — изолированные проверки.

## Выпуск

Измени `VERSION`, выполни сборку и проверки. В манифесте `dist/release-X.Y.Z.json`
укажи адрес ZIP: относительно манифеста или абсолютный HTTPS-адрес. Для локального
использования относительный путь разрешается относительно папки JSON.
При будущей публикации приложи ZIP, установщик и манифест к GitHub Release,
проверь SHA-256, после чего подключи URL манифеста в центре. Ветка Git сама по
себе не является каналом обновлений. Репозиторий и файлы пока локальные.

Политика лицензий и ссылки на исходники — в [THIRD-PARTY.md](THIRD-PARTY.md).
Границы фактической проверки — в [VALIDATION.md](VALIDATION.md).
