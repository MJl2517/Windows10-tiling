# Изменения

## 0.1.11

- Центр получает манифест и ZIP через GitHub Releases API без токена. Это обходит ошибку 504 на прямом адресе скачивания.

## 0.1.10

- Добавлены журналы установки, обновления, отката и удаления и кнопка открытия журналов в центре.
- Новые установки проверяют обновления через GitHub Releases; источник можно заменить в центре.
- Уменьшен зазор между настройками трея и кнопкой центра управления.

## 0.1.9

- Мастера Inno Setup и распространённые диалоги открываются в плавающем режиме с размером приложения.

## 0.1.8

- Трей каждые пять секунд убирает значки, чьи окна-владельцы закрылись без уведомления Zebar.

## 0.1.7

- Клик по дате открывает календарь Rosé Pine на том же мониторе: неделя с понедельника, переход между месяцами, кнопка «Сегодня», закрытие по Esc и потере фокуса.

## 0.1.6

- Десять пространств: 1–5 WEB, DEV, FILES, CHAT, TTRPG слева; 6–0 MEDIA, VPN, DOUBLE, OTHER, OTHER справа.
- Alt+0 и Alt+Shift+0 доступны в центре и справке; панель показывает все десять пространств, включая пустые.

## 0.1.5

- Добавлен отдельный компонент Command Palette: официальный PowerToys для текущего пользователя с проверкой SHA-256 и подписи Microsoft, существующая установка используется без перезаписи настроек.
- В центре доступны включение интеграции, запуск палитры и её настроек; в справке указано Win+Alt+Пробел. Компонент требует Windows 10 2004+; PowerToys сохраняется при удалении сборки.

## 0.1.4

- Повторная попытка обновления распаковывает проверенный архив заново и не использует неполные папки после сбоя.
- Откат сохраняет несохранённые правки в центре; сброс сочетания работает во время редактирования ячейки.

## 0.1.3

- В центре добавлены настройки горячих клавиш окружения с поиском, альтернативными сочетаниями и сбросом.
- Повторяющиеся назначения проверяются до применения; физические клавиши одинаковы в EN/RU.
- Пользовательские сочетания сохраняются при обновлениях, подсказка генерируется из тех же назначений.

## 0.1.2

- Центр управления оформлен в Rosé Pine: боковая навигация, отдельные блоки действий, тёмные поля и таблицы.
- Понятные названия, подсказки, сохранение источника обновлений в том же разделе и отметка несохранённых настроек.
- Установка обновления доступна после проверки; ошибки и результат операции остаются видны, опасные действия требуют подтверждения.

## 0.1.1

- Обновление автоматически приостанавливает и запускает служебный контроллер панели и обводок.
- Списки состояния имеют одинаковый формат и корректно обрабатываются центром.
- В восстановлении отображается проверка наличия файлов выбранных компонентов.

## 0.1.0

- Собраны конфиги, исходники дополнений и панели, зависимости с SHA-256.
- Добавлены установка для текущего пользователя, центр управления, локальные обновления,
  резервные копии, защита ручных изменений, откат и удаление.
- Сохранены физические хоткеи EN/RU и личные данные приложений.
