Горячие клавиши GlazeWM

Alt — основной модификатор. H/J/K/L — физические клавиши, независимо от языка.

WinПоказать / скрыть нижнюю панель Windows; сочетания Win+клавиша работают как обычно
Alt + ← / →Фокус на соседнее окно, включая другой монитор
Alt + H / J / K / LФокус влево / вниз / вверх / вправо
Ctrl + ↑ / ↓ · Alt + ↑ / ↓Фокус на окно сверху / снизу
Alt + Ctrl + ← / →Сдвинуть границу окна влево / вправо, шаг 5%
Alt + Ctrl + ↑ / ↓Сдвинуть границу окна вверх / вниз, шаг 5%
Alt + Shift + BРазделить выбранную часть: рядом ↔ друг над другом
Alt + Shift + ← / →Перенести окно на левый / правый монитор и сохранить фокус
Alt + Shift + Ctrl + ← / ↓ / ↑ / →Переместить окно внутри раскладки
Alt + 1…9Перейти на workspace
Alt + Shift + 1…9Отправить окно на workspace, остаться на исходном
Alt + Enter / Alt + RТерминал / список приложений — в текущем пространстве
Alt + TPowerShell в Alacritty — оформление как у Yazi
Alt + Q / Alt + FЗакрыть окно / fullscreen и обратно
Alt + Shift + QСвернуть активное окно
Alt + V · Alt + Shift + SpaceПереключить floating / tiled
Alt + B / Alt + EZen / Yazi — в текущем пространстве
Alt + , / .Фокус на левый / правый монитор
Alt + Shift + , / .Перенос между мониторами — альтернативные клавиши
Alt + Shift + R / WReload конфига / перерисовка окон
Alt + Shift + PПауза WM для игр; повторное нажатие — продолжить
Alt + Shift + EВыйти из GlazeWM и Zebar
Alt + EscМеню питания: сон, гибернация, выключение, перезагрузка, блокировка и выход
Alt + F1Эта подсказка
1 WEB · 2 DEV · 3 FILES · 4 CHAT · 7 TTRPG — основной монитор. 5 MEDIA · 6 OTHER — второй.
Alt+7 — TTRPG для вождения настольных ролевых игр; Alt+Shift+7 — отправить туда окно.
Окно в фокусе отмечено голубой рамкой; все окна полностью непрозрачны. Курсор сам между экранами не прыгает.
Esc, кнопка «Закрыть» или Alt+Q закрывают подсказку.
